# MovieHub

MovieHub is a movie booking website inspired by BookMyShow.


## Features

- User signup and login
- Password hashing
- Movie browsing
- Movie search
- Movies by genre and language
- Movie details
- Movie booking
- Seat selection
- Save movies to a personal collection
- View saved movies
- Remove saved movies
- Events section
- User dashboard

## Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- SQLite
- bcrypt
